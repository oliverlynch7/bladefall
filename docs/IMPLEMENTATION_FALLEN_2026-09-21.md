## Implementation and verification — 2.007.0-fallen-duel

Campaign-only `fallenDuel` bypasses the legacy Warden attack/crystal phases; other modes retain their fight. Flat release hall, four solid pillars, two side alcoves and enclosing stone walls, with high open/cutaway framing for camera visibility. Boss uses the existing articulated Warden at height 58 (player collision height 44), rather than a giant. Thrust: 1.05-second tell, final .65-second locked aim, .32-second swept advance up to 440 units; solid pillars stop it and grant 2.2 seconds recovery. Every third attack starts with a .55-second false move, then a separate .85-second sweep tell. Sweep has a 190-unit forward arc and 1.65-second recovery. Phase two shortens pursuit downtime, not warning duration. No reinforcements, damage floor or crystal shield. Damage is once per attack and respects cover, height, death/downed state and existing dodge/parry rules. Host chooses/advances; peers mirror attack geometry and check local damage. False-start/stagger torso poses preserve existing hand/weapon contacts. The winning journal note points toward Ellis in Frostfell; old former-Bladeborn descriptions were corrected for this boss.

Visual QA uncovered separate `mob3d.js` import versions: the animated renderer and global fallback query were different module instances. All five consumers now use the same URL, as do their dependent cache versions. This also reconnects level cleanup to the active actor pool. Verified actual animated model ownership across Briar (26 enemies), Hollow cliffs (9), Dungeons (9), Fallen (1), then Briar again (26), with no missing/live-count mismatches or renderer errors. This is a concrete overlap fix, not a claim that every remaining cosmetic/z-fighting issue is resolved.

Evidence:
- Isolated encounter tests: aim lock, noninstant thrust travel, feint delay, pillar stop, recovery, directional/height/dead/downed hit checks, bounds, repeated attack cycle and snapshot fields.
- Browser: 94 controller route samples, no failures; 13 runtime checks including actual damage, deduplication, dodge, class parry/riposte, solo second phase, death exit/north clue and shard retention. No browser errors.
- Controlled two-context co-op: six checks for locked aim/scale, host-only advancement, guest-local damage, repeated snapshot deduplication, shared death/exit and no additional enemies. Uses real packet handlers with a controlled relay; not an end-to-end WebRTC test.
- Existing four Keep shard/checkpoint tests and eleven campaign/legacy checkpoint tests pass. Story/authority/Rift Shards/Voice API tests pass; all 145 recording lines are unchanged.
- Three real browser screenshots reviewed. Hall kit measured 44,364 triangles and 50 visible kit draw calls in the preview view; not a device performance benchmark. Enemy import consistency has a regression test.

Tests freeze enemies/use invulnerability for traversal and controlled states for attack checks. Ordinary combat balance still needs playtesting. Wider lore in unconverted later levels remains queued for their implementation; this does not mark the full campaign or wider approved backlog done.
