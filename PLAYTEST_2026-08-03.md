## A. BROKEN — costs a run, or corrupts save state

- [x] **A1. Chronomancer trial does not spawn its 24 enemies.** Reproduced TWICE in a row: killed
      every enemy in the room and the trial could not complete. A trial that cannot be finished is
      the worst class of bug here — it burns a run and blocks a class unlock.
- [x] **A2. Quitting an incomplete trial leaves the class EQUIPPED.** Quit to hub without
      completing, came back with Chronomancer equipped. The Drillmaster correctly shows it LOCKED,
      so two systems disagree — the unlock check and the equip state. Equip must follow the unlock.
- [ ] **A3. Multi-hit sound on default class-trial weapons.** One hit plays several attack sounds
      spaced out. Oliver asked for this to be removed once already and it is still there. Needs a
      SINGLE-hit sound, and the old one gone rather than layered over.

      NOT FIXED. 2026-08-03 I diagnosed this as the game calling the impact sound once per ENEMY,
      and shipped a fix gating it to one per SWING (commit 49c8c63). That change is correct and
      worth keeping - a swing through three enemies did fire three impact sounds plus three
      rustyhit layers - but it is NOT what Oliver is hearing. His read, which is the one to act on:
      THE SOUND ASSET ITSELF IS A THREE-HIT SAMPLE, and it plays in full on every single hit. No
      amount of call-gating fixes a sample that contains three thuds. The fix is to crop the sample
      to its first transient or replace it. Find which asset the class-trial starter weapons
      actually play (SFX.hit / rustyhit / weaponImpact are three different sources - identify the
      one carrying the triple before touching any of them).
- [ ] **A4. Hollow Pass area 2: a gap only crossable with double jump.** Soft-locks anyone without
      it. Oliver was told a breakable-wall alternative had been added; it was not. FIND the exact
      gap, then add the breakable wall so the route works without double jump.
      (Do not claim this one done without a screenshot of the crossing.)

      DEFERRED to Oliver 2026-08-03: he will fix this himself in the level editor once it is
      finished. Measured so far - single-jump reach is 150 horizontal, 94 vertical; the Needle
      Forest pillar weave was the obvious suspect and is NOT it (gaps measure 46-47u). The gap is
      elsewhere on the required route.

- [ ] **C3. Drillmaster teaches the weapon matrix** — which classes can use which weapon types.

      have collision; the taller ones around them do not. Buildings do, spires do not. Benches and
      carts do not. Rule: every placed asset gets collision TRUE TO ITS VISUAL SIZE, by default.
- [ ] **E2. The new weapon models are still not in the game.** Only the default class weapons show.

- [ ] **E3. The mirror still reflects the OLD voxel character.** Should reflect the 3D model.
- [ ] **E4. The voxel model flashes for a moment on level load** before the 3D model appears.
      Should never be visible — hold the frame or the voxel draw until the 3D hero is ready.
- [ ] **E5. Old hub walls render see-through** in a way that does not read as intentional.

## F. THE BIG ONE — a decision, not a task

- [x] **F1. A LEVEL EDITOR Oliver can operate himself.** Place and tweak assets by hand, for the
      hub and the zones, from the available kits.

      His reasoning, and it is sound: he currently has to describe a layout in words, and I guess
      at it. Most of the world-building complaints in this very list (D3, E1, E5) are exactly that
      loop failing. An editor turns a paragraph of description plus three wrong attempts into him
      dragging something 40 units to the left.

      BUILT 2026-08-03, all four phases. F2 opens edit mode over the running game: click to select,
      drag to move, arrows to nudge, alt+arrows to resize, Delete to remove, Ctrl+Z/Ctrl+Y to undo.
      A palette places props, platforms, healing pads and movers. C toggles the collision overlay.
      Edits are stored as an edit list replayed over the generated level, so they survive
      regeneration; Export file produces something to commit.

      Still open on the editor itself:
        - the hub renders only lanterns and flowers as models, so the rest of the palette is
          disabled there (needs the matching entry in index.html's hub exclusion list, ~12308)
        - no mob spawners: every den carries a questId binding it to a quest's kill counter, and
          what a den without one does was never established

## G. Decisions taken 2026-08-03

- [x] **New difficulty mode is called CASUAL**, not Easy. Names the player's intent rather than
      judging their ability.
- [ ] **G1. Boss and mini-boss arenas must be SET, not procedural.** They currently fall through
      to the shared maze at `loadStage` (index.html ~5511), whose `rnd`/`rnd2` mix in `G.runSeed`
      - which is re-rolled per run (`runSeed: Math.floor(Math.random()*1e9)`, ~3579). Drop runSeed
      for `isBoss || isMini` so an arena is the same layout every time, exactly as the eight core
      zones already are via EXPANDED_SCAPES.
      Applies to the Boss Gauntlet too - a gauntlet of re-rolled arenas is not a gauntlet.
- [ ] **G2. THE ENDLESS DUNGEON - endless procedural dungeon-crawl mode.** (Name chosen by Oliver
      2026-08-03, replacing the working title "The Long Delve". Worth knowing: Amplitude's
      *Endless Dungeon* (2023) is an existing roguelite. As the name of a MODE inside Bladefall
      rather than the game itself, that is a collision of flavour, not of product - say so once and
      move on unless Oliver wants distance from it.) Start level
      zero as one of the three base classes, no gear. Nothing carries over: no XP, loot or gold,
      and no effect on the campaign save. Descend for a personal best. Classes can be FOUND as
      drops mid-run. Distinct from Abyssal Descent by being about exploration, routing and
      map-reading rather than combat endurance - so keep the dungeons wide and branching.
      Cheaper than it looks: the maze generator, the escrow system (class trials already swap your
      real loadout out and back via `meta.bank`/`trialReturnHero`) and the records all exist.

## What is SET vs PROCEDURAL (verified 2026-08-03, after getting it wrong twice)

SET, deterministic, same every run:
  - the hub (fixed literals in `enterWaystation`)
  - all 8 core zones and their areas - each has a terrain grammar in EXPANDED_SCAPES, dispatched
    with `mulberry(i*7919+31+so)`, which does NOT include runSeed

PROCEDURAL, re-rolled per run (the shared maze below that dispatch, seeded WITH runSeed):
  - class trials
  - side zones (the 7 hidden secret areas: Thornwood, Sunken Wash, Oubliette, Glacier Vault,
    Magma Core, Reaper's Gate, Reliquary - each hosts a class trial)
  - boss and mini-boss arenas  <-- G1 moves these to SET

The editor therefore needs no seed-pinning: the hub and all eight core zones are already stable.
