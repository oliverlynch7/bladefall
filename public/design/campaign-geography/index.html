How these plans guide the work
  1. Set the landmark, main journey and each branch’s purpose before changing the layout.
  2. Sketch entrances, returns, height changes and hazards at the existing scale.
  3. Review locked and open states. A lift, puzzle or parkour route must have a real spatial job.
  4. Build terrain and architecture to that plan; place props where people would use them.
  5. Walk the routes, inspect normal-camera views and test saves and co-op. Then playtest pacing and enjoyment.

These plans combine authored intent with captured initial-state game geometry. Floors, collision boundaries and exported paths use actual coordinates. Selected destinations are real quest objects or NPCs. Enemy markers are starting positions, not an encounter simulation. The Before view retains geometry from before the geography pass (9d143bd1); objectives remain current. Overlapping routes may be on different floors. Use the height layers.

Current work had already begun when these visual plans were requested. They are a review gate for that work; subsequent layout changes should start here. A blueprint is not evidence that a level is fun.
