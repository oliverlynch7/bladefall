## Other coverage: reuse or later polish

- Title/character creation: calmer instrumental Home Worth Saving variation. No early Bladeborn reveal in title-screen story cues.
- Ordinary conversations: soften the current environment music rather than starting a new full track for each NPC. Serious revelations can request a scene cue; comedic exchanges need not be scored like jokes.
- Mara's station and rescued shelter: quiet home/hub motif. Do not restart on every visit to a healing pad.
- Orb vision: Sky Library fades into a brief unsettling texture from Void arrival. No Ian melody or final-charge resolution that announces the ending solution.
- Optional quests, secret caves and code chests: usually retain local music; a short discovery sound is enough. Use the Rift motif for actual Rift Shards, not all rewards.
- Class trials: rhythmic Lessons Beyond the Rift variation initially; eight bespoke arrangements are optional polish, not eight urgent full compositions.
- Abyssal Descent: darker looping variation of Chamber of Inverted Gravity or The Black Procession, with Paradox Void Assault at higher-pressure encounters; audition first. Core campaign remains higher implementation priority.
- Arena/Gauntlet: Iron Juggernaut / Paradox Void Assault where appropriate. Keep Crown and Iron Oath exclusive to the final King to protect their impact.
- Treasure sprint/arcade: a separate playful fast loop is OPTIONAL later if current licensed placeholder is inadequate; storm-crossing music is a temporary possible reuse, not an ideal permanent identity.
- Credits: Watchful Greenwood reprise or a longer home-theme arrangement. Postgame hub can be warmer without constantly replaying the entire ending.
- Optional dedicated Marble Colossus track: monumental bells, heavy stone rhythm and Sunspire melody; desirable for boss variety, not a gap blocking first implementation because Iron Juggernaut covers it.

Existing game music remains a functional fallback until new tracks are assigned and approved. Preserve attribution for existing licensed music still used; do not label Oliver's tracks with those artists' licenses.

## Short sound/music cues, not full songs

Commission a small coherent cue pack separately: player level-up; clearly different class-rank-up; skill choice confirmed; quest complete; Rift Shard pickup; fifth-shard set complete; trial/class unlocked; boss victory/level complete; ordinary defeat; final-charge failure/reset; final-cut success. Durations roughly 1–5 seconds, longer only for a deliberate scene transition. Reserve triumph for success and give the hydra its release cue. Existing SFX can remain until replacements are accepted.

## Implementation routing and QA

Current musicForScene reads Z.mus for both halves, a boss key, hub, side and generic trial. Adding files alone would NOT deliver this plan. Add stable area/scene/phase routing, explicit cinematic override and restoration to the correct prior track. Final-boss phase-two music must start at the transformation, not only on entering the arena. Deliberately quiet pause during the plunge can make the second entrance matter; exact timing follows listening and animation.

Co-op host broadcasts scene/phase music events with encounter/dialogue state so both players hear the same story transition. Personal volume/mute remains local. Dialogue lowers music rather than burying voices; menus do not stack duplicate loops. Skip/retry must stop orphaned cues. Charge retry restarts only its own cue, not Ian's scene or the boss soundtrack.

Do not preload 99 MB at boot. Keep originals intact and stream only needed browser assets; current 193-kbps files are already compressed, so no automatic lossy re-encode is warranted. Audition loop seams/intro length, measure playback level/peaks and test low-volume intelligibility before choosing trims. Check on headphones and phone speakers. Verify all eight regions' two halves, every boss phase, death/retry, mute toggles, speech/music transitions, hub return, co-op scenes and restoration. Music should follow real state changes, not player proximity jitter.
