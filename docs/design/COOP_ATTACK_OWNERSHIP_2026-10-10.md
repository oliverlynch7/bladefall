# Co-op attack ownership pass

The current guest hit path relays raw damage before most class-specific hit behavior runs. The host then processes that hit using its own class, weapon and status rules. A guest Mage can lose an elemental buildup bonus, a guest basic class hook can do no durable damage or world effect, and a host Warlock can boost a guest's cursed hit. The authority boundary, rather than any one class card, is the defect.

Keep enemy health and death on the host. The guest executes the attacking player's movement and basic-attack identity locally, then relays attack context with each candidate hit. The host uses its own target state for armor, cover, shield, damage, statuses and kills. Attack context is bounded to class/passive markers, weapon speed/type, designated-hit status and explicit basic-hook effects. A receipt returns actual dealt damage so guest healing remains based on a real hit; rejected hits refund the basic hook's HP or mana cost. Do not change PvP, unrelated campaign rewards, saves or custom SFX.

Verification must use two real browser pages and the game's packet handlers. Compare solo/guest damage and effects for multiple classes, including elemental weapon buildup, a basic-hook status, designated Rune/Corruption payoff, host-class noninterference, duplicate receipts, companion/projectile hits and existing co-op kill rewards. Run a pre-change save, syntax gate and the relevant campaign/co-op regressions. This is a transport correctness pass; it cannot establish class balance or real-internet latency.

## Implementation and verification

Guest hits now carry class, selected offensive passive bits, weapon buildup timing, designated intent and basic-hook effects. Direct guest elemental skill status requests and host enemy-status snapshots keep both players' view of buildup aligned. Ranger marks, Warlock curses and Reaper Death Marks carry their caster's identity; the host applies their damage or burst once, and mirrors receive their visual state. Host-owned burn/venom damage no longer ticks a second time on the guest mirror. A rejected hit returns spent Mage mana or Warlock HP and does not apply Mage Savant buildup. Two browser pages exercised the actual host/guest packet handlers for Ranger, Warrior, Mage, Warlock, Reaper, companions and projectiles, including a Death Mark kill without duplicate burst. Existing class/PvP healing, duplicate receipt, co-op kill rewards and Thunder Cliffs co-op route checks passed, as did a pre-change save load and the static syntax gate. A remote-network playtest is still useful for timing and feel; this pass does not rebalance classes or cover every non-elemental skill debuff.
