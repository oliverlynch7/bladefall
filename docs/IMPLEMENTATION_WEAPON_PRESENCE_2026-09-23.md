# Weapon size and elemental readability

U186/U187 authority: most weapons slightly oversized; dagger < sword < greatsword, spellblades distinct, existing assets/grips preserved, avoid body clipping. Inspect first: normalized sword1.2, great1.6, dagger.64-.66, spellblade1.3; original greatsword is only33% longer than sword and narrower than some sword guards. Source meshes are cached/shared; uniform model scaling would enlarge handles and detach support contacts. Pole/staff rear shafts already extend well below the hand, so extending those rear ends risks body/ground clipping.

Plan: clone only owned weapon geometry at equip time, deform in normalized grip coordinates, preserve the entire handle/support zone, extend and broaden distal blades/heads by family. Keep lower pole/staff shafts unchanged. Grow bow limbs symmetrically and move string endpoints consistently. Maintain source UVs/materials and triangle count. Give compact crossbow front limbs/rail and Pirate saber/barrel modest forward-only growth while protecting contacts/stock. Consolidate the existing six element accent colors and migration aliases across ordinary weapons and crossbows; improve color retention without changing damage/status rules. Measure actual sizes, protected vertices, hand/support contacts, body/ground clearance and review moving/attack screenshots. Reduce any problem family after evidence. Verify peer/mirror, cleanup and old save. Publish previews and validated batch.

Inspection during elemental QA found the mirror player was excluded from colorWeapon because it is a separate player object. Fix the mirror render path as well as the saturated blade/head filter. This is why changing elements in the mirror produced identical colors despite valid palette values.
